# Contributing to DataBounty datasets

This repository is the public catalogue for **released** DataBounty dataset artifacts. It is not the place to
submit new dataset items, sponsor references, reviewer material, credentials, or unpublished work.

## Contribute dataset work

Use [DataBounty](https://databounty.io) to find an open dataset specification, submit items, and follow the
review flow. Contributors receive the credit described in each published release once that release is approved.

## Improve the public catalogue

Use the issue forms in this repository for a factual correction, licensing question, or withdrawal request.
Please include the public dataset path and enough detail to reproduce the concern. Do not include personal data,
credentials, unpublished submissions, or sponsor reference material.

Pull requests that add or alter released dataset artifacts are not accepted. Publication is handled through the
DataBounty release process so the artefacts, manifest, licence, and attribution remain consistent.

Questions: [support@databounty.io](mailto:support@databounty.io).

# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Send a concise report to
[support@databounty.io](mailto:support@databounty.io) with **Security report** in the subject line instead.

Include the affected public URL or file path, a description of the impact, and safe reproduction steps. Do not
send credentials, access tokens, personal data, or unpublished dataset material.

## Scope

This repository contains released dataset artifacts and catalogue documentation only. For a concern about a
dataset's content, licence, attribution, correction, or withdrawal, use the relevant issue form rather than a
security report.
